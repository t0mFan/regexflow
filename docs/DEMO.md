# Demonstration walkthrough

1. Show the English workbench and muted charcoal theme. There is one instruction box with no transformation-type, target-column, or replacement-value selector.
2. Connect S3 and import CSV/XLSX, or load demo data. Open **View sample** and explain that each instruction sends column names and up to eight sample rows to the configured provider; the full table stays local.
3. Enter “Set all Notes values to test and trim Name.” Show the selected steps and resulting table.
4. Enter “Change it.” Show **Needs clarification** and confirm the table remains unchanged.
5. Reply “Set Notes to done. Leave everything else unchanged.” Show that this edits the latest successful result.
6. Enter “Keep only Name.” Show automatic column selection.
7. Show **View original** and **Reset to original** to demonstrate source preservation.
8. Show task history and Flower task status.

Real S3 listing and import of `s3-test.csv` were verified locally with three rows and three columns. The final recorded video and public deployment are not complete.
